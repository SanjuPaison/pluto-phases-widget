Privacy Policy — Pluto Phases Web Widget

This policy covers the "What Was Happening?" web widget only. The separate Pluto Phases Gems app has its own privacy policy, since the app and this widget handle data differently (the app processes everything on-device with no network connection at all; this widget necessarily sends information to a small number of services in order to compute and deliver a reading).

1. Birth and Event Information You Enter

When you enter your birth date, time, place, gender, an event date, and a description of an event into this widget, that information is sent to a server-side function ("the reading service") that computes your chart and Pluto transit reading for that one request. It is used only to produce your result and is not retained beyond what is needed to do so and to enforce the usage limit described in Section 5.

2. Geocoding Your Birth Place

To convert the birth place you type (e.g. a city name) into map coordinates, the widget sends that text to OpenStreetMap's Nominatim service, a third-party geocoding provider. That request is subject to Nominatim's own privacy practices; see osmfoundation.org.

3. If You Request the Full Report or a Consultation

If you select the Pluto Phases Transit Report and/or the Consultation option and continue, the birth details, event details, and your computed reading are sent by email (via the EmailJS service) to Sanju Paison at lifeprediction.net, so your request can be followed up on directly. This only happens if you actively select one of these two options — simply using the widget to explore a past event does not send anything to us. The Kindle eBooks option requires and sends no personal information, since it is simply a link to a public Amazon storefront.

4. Translation

If you use the "Translate this reading" feature, the text of your computed reading is sent to the MyMemory translation service to produce a translated version. This is only triggered if you actively choose a language other than English.

5. Rate Limiting

To prevent automated abuse and protect the reading system, the number of readings a given internet connection (IP address) can request in a day is limited. This is tracked only as a short-lived counter tied to an IP address on a rolling 24-hour basis; it is not linked to any personal information you entered and expires automatically.

6. Third-Party Information

This widget may be used to generate a reading based on information about someone other than you (for example, entering another person's birth date). If Section 3 applies to that request, the same handling described there applies to that person's information as well.

7. This Website

This widget is designed to be embedded on lifeprediction.net, which is currently hosted using GoDaddy and built on the Nicepage platform. Like most website hosting arrangements, this may involve the automatic collection of standard technical data as a normal part of serving web pages — for example, IP address, browser type, and access times — which is handled by the hosting provider rather than actively collected by the developer. The hosting provider and platform used for this website may change over time. The widget's own code and data are additionally hosted on GitHub Pages and Cloudflare.

8. Analytics

This website may use one or more third-party analytics services to measure visits and engagement. These services may collect standard technical information such as IP address, device/browser type, approximate location, and pages viewed. The specific analytics provider(s) in use may change over time; current details can be requested via the contact method below.

9. What This Policy Does Not Cover

This policy covers this web widget and the lifeprediction.net website only. It does not cover any third-party service you may be directed to (for example, EmailJS, OpenStreetMap, MyMemory, GitHub, Cloudflare, Amazon, or a payment processor), each of which has its own separate privacy practices.

10. Changes to This Policy

This policy may be updated from time to time, including to reflect changes in hosting provider, analytics provider, or the services this widget relies on. Continued use of the widget or website after changes are posted constitutes acceptance of the updated policy.
